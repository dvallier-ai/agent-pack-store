# Changelog — Ollama Local Agent Kit

## [0.1.0] — 2026-09-16

### Added
- `install.sh` — curl/Ollama checks, model pull notes, optional venv.
- Python agent (`agent/`) — single-shot + chat loop, Ollama HTTP, tool stub.
- Eval harness (`eval/`) — 3+ fixtures, JSON + Markdown reports.
- Helper scripts: smoke, pull-model, run-eval.
- Docs: architecture, troubleshooting, swap models.
- `.env.example` — host/model/system prompt (no secrets).
