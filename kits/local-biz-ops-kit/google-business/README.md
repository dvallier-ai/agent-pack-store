# Google Business Profile — post drafts

Ten editable drafts for a locksmith / home-services shop. Customize city, hours, offers, and photos before posting in Google Business Profile (or your GBP management tool).

**How to use:** open a `.md` file → edit bracketed bits → copy body into a new Google post. Optional helper: `python3 scripts/generate-gbp-week.py` builds a week plan from these templates.
