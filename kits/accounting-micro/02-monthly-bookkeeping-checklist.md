**Print one per month.** Fill the header; check boxes as you go.  
**Audience:** Side hustles & solopreneurs keeping their own books.

> Sales-tax row is a **reminder checkbox only** — it does not tell you whether you owe sales tax.

## 1. Close the prior period hygiene
- [ ] Back up / export a copy of the file or reports (date-stamp the filename)
- [ ] Note last reconcile date for each bank/credit account: _______________
- [ ] List open questions for myself / my bookkeeper (sticky note OK)

## 2. Pull source data
- [ ] Download bank CSV / OFX for the month
- [ ] Download credit-card CSV for the month
- [ ] Download processor payouts (Stripe / PayPal / Square / Shopify) if used
- [ ] Collect receipt photos / PDFs into one folder: `receipts/YYYY-MM/`
- [ ] Redact full card numbers from anything you paste into an LLM

## 3. Reconcile
- [ ] Reconcile primary checking to statement ending balance
- [ ] Reconcile credit card(s) to statement ending balance
- [ ] Investigate any unmatched cleared items > $X threshold I set: $______
- [ ] Record bank fees / interest shown on statements

## 4. Categorize transactions
- [ ] Clear uncategorized / “Ask my accountant” style buckets
- [ ] Split any mixed personal+business charges (or mark personal)
- [ ] Match processor deposits to sales (don’t double-count payouts + gross sales)
- [ ] Flag transfers between own accounts as transfers — not income/expense
- [ ] Owner draws / contributions labeled correctly (not “expense” by default)
- [ ] Optional: run receipt→category prompt (`01-…`) then **verify every suggestion**

## 5. Receipts & support
- [ ] Attach or file receipts for material expenses (rule of thumb: anything I’d hate to explain later)
- [ ] Note business purpose on meals / travel lines (who / what / why) — factual notes only
- [ ] Missing receipt list written down (chase vendors / email search)

## 6. Income sanity
- [ ] All invoices for the month issued (or marked why not)
- [ ] Payments applied to the right invoices
- [ ] Refunds / chargebacks categorized consistently
- [ ] 1099 / contractor payment list updated if I hire help (process is mine / my pro’s)

## 7. Sales tax reminder *(checkbox only — not a determination)*
- [ ] I checked **my own** sales-tax / marketplace-facilitator situation for this month (nexus, filings, or “N/A for my facts”)  
  _If unsure: stop and ask a licensed pro — this pack will not decide for you._

## 8. Reports glance (for *your* eyes — not filing)
- [ ] P&L for the month looks plausible (no mystery spikes)
- [ ] Balance sheet / account list: no duplicate “misc” dumpsters growing forever
- [ ] A/R aging: follow up on overdue invoices
- [ ] A/P: bills due next 14 days noted

## 9. Lock & handoff
- [ ] Month marked closed / locked if my tool supports it (or freeze the sheet tab)
- [ ] One-paragraph note to future-me: odd items this month
- [ ] If using a pro: share redacted questions list only

## Done definition
- [ ] Banks reconciled  
- [ ] Uncategorized under my personal tolerance  
- [ ] Receipts folder exists for the month  
- [ ] I did **not** treat AI output as final
