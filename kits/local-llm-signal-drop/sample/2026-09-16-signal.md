## 2. VRAM ballpark table (illustrative)

Assumptions: 4-bit-class quant (e.g. Q4_K_M-ish), short context (~2–4k), single user, batch 1. **Real** usage depends on quant, context length, KV cache, and backend. Treat as planning order-of-magnitude, not a guarantee.

| Model class (public families) | Params (approx) | Ballpark VRAM (Q4-class) | Notes |
|-------------------------------|-----------------|---------------------------|-------|
| Tiny / edge (e.g. Llama 3.2 1B-class) | ~1B | ~1–2 GB | Good smoke/eval default |
| Small laptop (3B–8B class) | 3–8B | ~3–6 GB | Common 8GB laptop zone |
| Mid desktop (13B–14B class) | ~13–14B | ~8–10 GB | Tight on 8GB; comfortable on 12–16GB |
| Upper consumer (32B–34B class) | ~32–34B | ~18–22 GB | Often wants 24GB class GPUs |
