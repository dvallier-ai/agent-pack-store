FAQ

Is this cloud inference?

No. The kit targets local Ollama only (http://127.0.0.1:11434). Cloud endpoints are out of scope for v0.1.0.

Do I need an API key?

Not for the default local setup. Configuration uses host/model/system prompt only — see .env.example.

Can I pay right now?

Yes via Lemon checkout. The store is still in test mode (identity/Activate Store pending), so treat card purchases as test until go-live. BTC payment is live now via pay-btc.html.

What model does it use?

Default is llama3.2:1b (or similar small model). Swap via OLLAMA_MODEL — see kit docs.
