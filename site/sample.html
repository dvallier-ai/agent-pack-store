Try a taste: local Ollama agent snippet

One copy-paste Python script that hits localhost:11434. Offline only — no cloud API keys. The full kit adds install scripts, a chat/tool loop, and an eval harness.

Requires: Ollama running locally with a small model pulled (e.g. ollama pull llama3.2:1b then ollama serve).

Snippet

#!/usr/bin/env python3
"""Minimal local Ollama call — taste of the Agent Pack Store kit."""
import json, urllib.request

OLLAMA = "http://127.0.0.1:11434/api/generate"
MODEL = "llama3.2:1b"  # change if you pulled a different tag
PROMPT = "Reply in one short sentence: what is a local LLM agent?"

payload = json.dumps({"model": MODEL, "prompt": PROMPT, "stream": False}).encode()
req = urllib.request.Request(OLLAMA, data=payload, headers={"Content-Type": "application/json"})
with urllib.request.urlopen(req, timeout=120) as resp:
    data = json.load(resp)
print(data.get("response", data))

Verify

  1. Save as taste.py and run python3 taste.py.
  2. You should see a short plain-text reply from the model (not an HTTP error).
  3. If connection refused: start Ollama, confirm the model tag, retry.
